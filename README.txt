ПВБ (Поволжский банк) — прототип бронирования помещений для юрлиц

КАК ЗАПУСТИТЬ
-------------
1. Установите Python 3.8+ с сайта python.org (при установке
   отметьте галочку "Add Python to PATH"). Другие программы
   и библиотеки НЕ нужны.
2. Откройте командную строку в этой папке.
3. Вариант А (Windows): дважды кликните run.bat
   Вариант Б (любая ОС): выполните   python app.py
4. Откройте в браузере:  http://127.0.0.1:5000
5. Остановить сервер: Ctrl+C в окне консоли.

ЧТО ГДЕ ЛЕЖИТ
-------------
app.py                 — вся логика сайта + встроенный веб-сервер + код создания БД
pvb.db                 — база данных SQLite (создаётся сама при первом запуске;
                         удалите файл, чтобы сгенерировать демо-данные заново)
static/css/style.css   — оформление (зелёные цвета Сбера)
static/img/*.png       — заглушки фото помещений и зданий
run.bat                — запуск одним кликом под Windows
README.txt             — этот файл

СТРУКТУРА БАЗЫ ДАННЫХ (SQLite, файл pvb.db)
-------------------------------------------
cities       — города (Ульяновск, Самара, Пенза, Тольятти)
buildings    — административные здания: город, название, адрес
rooms        — помещения: метраж, вместимость, тех. характеристики,
               оборудование, стоимость ₽/час, требуется ли СКУД, фото
bookings     — бронирования: дата, время начала/конца, помещение,
               название юрлица, контакты, статус (active/cancelled)
participants — посетители для помещений с СКУД: ФИО, паспорт, должность

КАК ЭТО РАБОТАЕТ
----------------
1. На главной выбираете город → здание → помещение.
2. На странице помещения — таблица доступности на 14 дней
   (09:00–20:00, по 1 часу). Занятые слоты подсвечены красным —
   они считаются из таблицы bookings.
3. Клик по свободному слоту «+» → форма бронирования: дата/время,
   данные юрлица, длительность (1–4 ч) и итоговая стоимость.
4. Если помещение требует СКУД (бейдж «Нужна проходка»), форма
   дополнительно требует состав посетителей (ФИО + паспорт каждого).
   Без посетителей бронь не создастся.
5. При сохранении проверяется пересечение по времени: если слот
   уже занят — бронь отклоняется с сообщением.
6. Страница «Все бронирования» показывает таблицу записей из БД
   и позволяет отменять брони (слот сразу освобождается).

КАК ЗАМЕНИТЬ ДЕМО-ДАННЫЕ НА РЕАЛЬНЫЕ
------------------------------------
Откройте pvb.db программой "DB Browser for SQLite" (бесплатная)
или выполните SQL-запросы к таблицам cities/buildings/rooms.
Демо-данные создаются в функции init_db() и в словарях
CITIES / BUILDINGS / ROOM_TYPES в начале app.py.
